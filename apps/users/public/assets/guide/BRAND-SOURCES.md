# Third-party visual assets

- `jupyter-brand.svg`: unmodified Project Jupyter logomark
  [official source](https://github.com/jupyter/jupyter.github.io/blob/main/assets/jupyter/logo/logomark-orangebody-greyplanets.svg).
  The Jupyter logo is used to identify access to the upstream Jupyter notebook
  environment, without implying endorsement. Respect
  [Jupyter's trademark guidance](https://jupyter.org/governance/trademarks.html).
  Source repository publishes the project under BSD-style terms.
- `slurm-brand.svg`: **locally redrawn** blue-tile motif based on
  [SchedMD's displayed Slurm logo](https://www.schedmd.com/images/slurm-logo.png).
  Not represented as an official SVG supplied by SchedMD. Used for identification
  of the Slurm workload manager, not as an endorsement or affiliation.

Do not replace upstream logos with invented "official" artwork. Retain these
source and usage attributions whenever the assets are redistributed.
